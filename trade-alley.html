02 / SOURCE CHECK

WFC vs. Superflex sources

Compare WFC’s dynamic market value with a source’s independently normalized Superflex value. The source’s original rank or value remains visible; raw scales are never averaged or treated as equivalent.

03 / MODEL & INPUTS

Explainable by design

History

Preseason values are labeled WFC model reconstructions. From the regular season forward, each refresh saves a daily WFC value snapshot.

News and schedule

Commissioner-reviewed, dated signals can move a value immediately. With no active signal, the relevant component remains neutral.

External charts

Provider charts remain source-attributed comparison or permitted-import references. They are never scraped, copied, or reverse engineered into the WFC model.

04 / PROVENANCE

Sources & limits

External data is not fetched from the browser or by this site. DraftSharks and the other provider entries remain attribution links and import contracts only; a reviewed, permitted snapshot is required before any external value is displayed.
